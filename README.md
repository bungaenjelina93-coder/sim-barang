
# SIM-Barang

## Deskripsi Proyek
SIM-Barang adalah sistem informasi untuk membantu pencatatan,
pengelolaan, dan pemantauan inventaris barang jurusan atau laboratorium.

## Tujuan
- Mencatat data inventaris barang.
- Mengelola kategori dan jumlah barang.
- Memantau kondisi barang.
- Mempermudah pengelolaan data inventaris.

## Konsep HTTP Request dan HTTP Response

### HTTP Request
HTTP Request adalah permintaan yang dikirimkan oleh browser
kepada server untuk meminta halaman atau mengirimkan data.

### HTTP Response
HTTP Response adalah jawaban dari server kepada browser
berupa halaman, data, atau status permintaan.
